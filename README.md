# Sprint_5 — UI-автотесты для сервиса «Доска»
Проект содержит UI-автотесты для (https://qa-desk.education-services.ru/).

## Структура проекта
Sprint_5/
conftest.py               # Фикстуры pytest (драйвер, генерация email)
locators.py               # Локаторы элементов и тестовые данные
tests/
    test_registration.py  # Тесты регистрации пользователя
    test_login.py         # Тесты авторизации пользователя
    test_logout.py        # Тесты выхода из аккаунта
    test_ads.py           # Тесты создания объявлений
README.md
.gitignore


## Покрытые сценарии
Регистрация: успешная регистрация, невалидный email, регистрация существующего пользователя
Логин: успешная авторизация
Логаут: выход из аккаунта
Объявления: попытка создания без авторизации, создание авторизованным пользователем


## Установка зависимостей
pip install selenium pytest


## Запуск тестов
pytest tests/


## Настройка тестовых данных

Перед запуском убедитесь, что в `locators.py` указаны данные существующего пользователя:

EXISTING_EMAIL = "testuser@test.com"
EXISTING_PASSWORD = "Password123"


Необходимо арегистрировать пользователя вручную через сайт перед первым запуском тестов.
